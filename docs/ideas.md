# Five demo directions

All examples can use fictional Spanish instruments and small, labelled fixtures.

| Demo | Clairic extracts | Clef decides | Visible result |
| --- | --- | --- | --- |
| Amendment intake | Target, article number, stated dates | Replacement, addition, repeal, other, unclear | A candidate change with source evidence; implemented here |
| Article boundary guard | Optional heading text | Outer article, quoted replacement article, uncertain | A segmentation preview that exposes ambiguous headings |
| Commencement clause lens | Explicit and relative dates | Explicit, relative, absent, ambiguous | Candidate dates checked with deterministic arithmetic |
| Gazette index locator | Instrument name, number, page | Optional match review | Searchable index cards with source spans |
| Citation review | Cited instrument and article | A match among supplied candidates, or unresolved | Citation candidates with evidence and unresolved cases |

Amendment intake is the first example because it demonstrates both model families in one small flow.
Date arithmetic should be verified in application code. The citation example should retain an unresolved option.
None of these examples needs to infer an instrument's legal status.
